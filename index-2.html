Project Overview

What is PrintGuard AI?

The project studies relationships between 3D printing settings and print outcomes using machine learning. A model must be trained and evaluated with real, labelled experiment data before its predictions can be considered reliable.

01 · INPUT

Print settings

Record the same five settings for every print job.

02 · LEARN

Machine learning

Train and compare models using successful and failed print records.

03 · OUTPUT

Failure prediction

Evaluate how well the model classifies unseen print jobs.

Five Main Inputs

Parameters that matter

Start with these five inputs for a focused first model. Suitable values depend on printer, filament and slicer profile.

01

Nozzle Temperature

°C · Influences filament melting and extrusion.

02

Bed Temperature

°C · Influences first-layer adhesion and warping.

03

Printing Speed

mm/s · Affects extrusion consistency and layer formation.

04

Layer Height

mm · Influences layer bonding and print geometry.

05

Cooling Fan Speed

% · Controls cooling of deposited filament.

Methodology

How the project works

Consistent data collection is essential for a meaningful model.

STEP 1

Record each print

Log five settings and the actual result: Successful or Failed.

STEP 2

Train and test

Keep print jobs separate between training and testing; compare suitable classifiers.

STEP 3

Report honestly

Show accuracy, precision, recall, F1-score and confusion matrix from test data.
